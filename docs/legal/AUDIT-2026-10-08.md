# Independent audit, 2026-10-08

An independent, read-only audit (a separate model run, instructed to be adversarial) checked the Privacy Policy and Terms
against the code, the live site and the repository. Its headline: the system is close to a reasonable small-operator GDPR
standard but had five blocking problems, and "cannot be sued or taken down" is not achievable by any system; the realistic
goal is a low-probability, cheap-to-defend position. This file records each finding and its status. The public text and the
code were corrected in the same change.

## Fixed in code or text

| Id | Finding | Fix |
|---|---|---|
| C1 | New Google accounts got a public display name derived from the email address ("Nobody else sees your email" was false) | Names are now `Player####`; the email local part is never used. Existing accounts renamed by `manage.py rename_email_derived_names` (see below) |
| C3 | Policy said the photo classifier runs on our service; it is not deployed and uploads return 503 | Policy states photo upload is switched off until the check is live |
| C4 | Policy said moderation records last 12 months; strikes never expire | Policy now says events and IP hashes 12 months, strike count and ban status stay with the account |
| H1 | A banned-then-deleted account kept more than the policy listed | Code clears last login, consent timestamps and age group; the policy lists what remains (events, address hashes, creation date) |
| H2 | 13-15 year-olds were public by default | Teens are excluded from the global leaderboard and found only by exact player ID |
| H3 | GitHub Actions (holds the production database URL) and AI-assisted dev tooling were not disclosed | Added to the policy and the record of processing |
| H4 | Terms and policy promised notice of changes with no mechanism | Wording changed to what can be done: update the date and describe changes; a home-page notice for 14 days for significant changes (operator duty, see RUNBOOKS) |
| M1 | Login errors revealed whether an account exists | One generic message |
| M3 | Anonymous answer logging was unthrottled | 120 requests per hour per client |
| M5 | Raw IPs sit in the rate-limit cache table | Disclosed in the policy |
| M6 | Photo responses were cacheable for a year | One day |
| M7 | Ban notice lacked "automated" and the appeal route | Added to the payload and the ban screen |
| L5 | DSA contact languages | Terms: English and Romanian |
| Deletion | Missed guest feedback with the same email, token rows, admin-log lines | Now deleted |
| Export | Missed several fields (Google id, canonical email, feedback email/status/admin note, guess times, Wordle device id, moderation events by public id) | Now included |
| Bug | Refreshing a token of a deleted account returned 500 | Now 401 |
| Docs | Stale statements (address "missing", wrong region, missing RETENTION.md) | Corrected |
